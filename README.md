# Voices ♡

给直播间挑一个喜欢的声音。

**[打开声音选择页 ↗](https://litomore-live.github.io/voices/)**

共 18 个音色，点击试听，选好后告诉主播名字就好。包含 Siri 普通话、台湾国语和粤语声音。
